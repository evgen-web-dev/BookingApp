# Reviews

Written here, never by hand:
- `<scope>-review.md` — by /review-as-mentor at phase close
- `archive-import-review.md` — by /import-history, once per imported project

Findings are ordered Blocking → Should fix → Consider → Question. A review records
what was found; it is not a task list. Anything that must be acted on later goes to
debt.md with a permanent ID, or this directory quietly becomes a second ledger.
